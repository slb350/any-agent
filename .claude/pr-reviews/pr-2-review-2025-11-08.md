## Critical Issues (Must Fix Before Merge)

### 1. **Incorrect Field Name in HookDecision Example** 🚨
**Severity**: CRITICAL (Confidence: 100%)
**File**: `open_agent/types.py:358-359`

**Issue**: Documentation example uses `should_proceed` which **does not exist**. The actual field name is `continue_`.

**Current (WRONG)**:
```python
>>> async def security_gate(event):
...     if event.tool_name == "dangerous_tool":
...         return HookDecision(should_proceed=False, reason="Blocked")
...     return HookDecision(should_proceed=True)
```

**Correct**:
```python
>>> async def security_gate(event):
...     if event.tool_name == "dangerous_tool":
...         return HookDecision(continue_=False, reason="Blocked")
...     return None  # Or HookDecision(continue_=True)
```

**Impact**: Users copying this example will get runtime error:
```
TypeError: __init__() got an unexpected keyword argument 'should_proceed'
```

**Fix Required**: Change all instances of `should_proceed` to `continue_` in types.py

**Location**: `/Users/stephenbrandon/Dev/any-agent/open_agent/types.py:358-359`

## Important Issues (Should Address)

### 2. **Invalid Regex Escape Sequence Warning**
**Severity**: HIGH (Confidence: 95%)
**File**: `open_agent/hooks.py:284`

**Issue**: SyntaxWarning - Invalid escape sequence in regex pattern will appear at runtime:
```python
sanitized = re.sub(r'\b[\w.-]+@[\w.-]+\.\w+\b', '[EMAIL]', event.prompt)
```

**Fix**: Use raw string for replacement:
```python
sanitized = re.sub(r'\b[\w.-]+@[\w.-]+\.\w+\b', r'[EMAIL]', event.prompt)
```

**Impact**: Python 3.12+ will show deprecation warnings, Python 3.14+ may error.

### 3. **Missing Documentation for Hook Chaining Behavior**
**Severity**: MEDIUM (Confidence: 85%)
**File**: `open_agent/hooks.py`

**Issue**: Documentation doesn't explain what happens when multiple hooks are registered:
- Which hook executes first?
- Do all hooks run, or does first decision stop execution?
- Can hook modifications stack?

**Code inspection shows**: First hook returning `HookDecision` stops chain (subsequent hooks don't run).

**Recommendation**: Add to hooks.py module docstring:
```python
"""
Hook Execution Order:
- Hooks execute in registration order (list order in AgentOptions.hooks)
- First hook that returns HookDecision stops evaluation (subsequent hooks don't run)
- Return None to pass control to next hook
- If all hooks return None, execution continues normally
"""
```

### 5. **Character-Based Token Estimation - Language Limitation Not Documented**
**Severity**: MEDIUM (Confidence: 90%)
**File**: `open_agent/context.py:245`

**Issue**: Documentation states "1 token ≈ 4 characters (for English text)" but doesn't warn about other languages.

**Code reality**:
```python
return math.ceil(total_chars / 4)  # Only accurate for English
```

**Impact**: Non-English text (especially CJK languages) will have significantly different token-to-character ratios, leading to incorrect context window management.

**Recommendation**: Add warning:
```python
"""
Note: The 1 token ≈ 4 chars ratio is calibrated for English.
Non-English text (especially Chinese/Japanese/Korean) may have
significantly different ratios. For production multilingual apps,
install tiktoken for accurate counting.
"""
```
